# Heardback — brief for view-building agents

Heardback is a job-search + application-tracking web app for early-career job seekers (internships, new grad). Tagline: "Know which jobs are real, who actually replies, and what to do next." It ships as ONE html page (a claude.ai Artifact) built from `src/` by `python3 tools/build.py` → `dist/index.html`; job data ships beside it in `dist/data/jobs.json` + `dist/data/companies.json` (fetched with relative URLs). Read `NOTES.md` (platform limits) and `SPEC.md` (product spec) once.

## Hard rules
- Only edit the files you are assigned. NEVER edit `src/js/00-core.js`, `10-ui.js`, `20-data.js`, `25-logic.js`, `30-shell.js`, `99-boot.js`, `src/styles.css`, or `src/index.template.html`. If you need a helper, define it in your own file with a prefix unique to your area (e.g. `find_`), or describe the needed core change in your final report.
- All JS files are concatenated into ONE classic script (core files first, then `src/js/views/*.js` alphabetically, then boot). Top-level `const`/`function` names are global and must not collide — prefix private helpers with your area name.
- Put CSS for your area in your own `src/css/<area>.css`. Use ONLY the tokens in `src/styles.css` `:root` (colors, fonts, sizes, radii). No literal colors. Max 5 font sizes: var(--fs-xs/sm/md/lg/xl). Reuse existing classes first (see styles.css: .page, .page-head, .card, .card-head, .card-body, .btn variants, .badge kinds, .chip, .seg, .input/.select/.textarea, .field, .list, .table, .empty, .skel, .stat/.stats-row, .split, .grid .cols-N, .row/.stack, .kv, .callout, .ai-box, .job-row, .board/.col/.app-card, .timeline/.tl-item, .round, .task, .funnel-row, .onboard*).
- Rendering: Preact 10 + htm. `html\`...\`` tagged templates, hooks `useState, useEffect, useMemo, useRef, useCallback`. Components use `html\`<${Comp} prop=${x} />\``. Use `class=` not className. Every form control needs a stable unique `id`. Lists need `key`.
- The frame blocks: alert/confirm/prompt (use `askConfirm({title, body, confirmLabel, onConfirm})`), `<a download>` (use `saveFile(name, text, mime)`), window.open (use `<a href target="_blank" rel="noopener">`), external fetch (only `data/...` files). localStorage is wrapped by the store already.
- Claude in the page (`caps.sample`) runs on the VIEWER's own Claude account, asks consent on first call, may be null. Every AI feature: show the button only when `caps.sample` is truthy (use `useCaps()`), call only on explicit click, show "Thinking…" state + Stop (AbortController), handle errors with `aiErr(e)`, and always offer a non-AI fallback (template/rule-based). Use `askClaude(prompt, {onText, signal, modelTier})` or `askClaudeJSON(prompt, {...})`. Never put the user's name/email in prompts unless needed. Label AI output with `<span class="ai-label"><${Icon} name="spark"/>Drafted by Claude. Review before sending.</span>`.
- Honesty: never present example or estimated data as real. Example applications have `a.example === true` → show `<${ExampleTag}/>`. Never invent company facts; anything Claude writes about a company must be labeled as AI-generated and "verify before relying on it".
- Copy: plain, specific, active voice. Buttons say exactly what happens. No emoji. No exclamation marks except a genuine celebration. Errors say what happened + what to do.
- Design bar: calm, focused, top-tier productivity tool. Dense where useful, generous whitespace elsewhere, strong hierarchy via weight/color, consistent 8px rhythm, 1px borders, no gratuitous shadows/gradients, tabular numbers for figures. Every screen has a designed empty state (what goes here + one button). Mobile at 375px must work (no horizontal page scroll, 44px tap targets, stacked layouts).

## Globals you can use (from core)
- State: `store.get()`, `store.set(fn)`, `useStore(selector)`. State shape: `{ profile:{roles[],levels[],locations[],remote,needsSponsor,resume,skills[],onboarded,name,weeklyGoal}, apps:{[id]:App}, settings:{theme,followUpDays,ghostDays,shareAnon,showExamples}, dismissed:{}, ui:{pipelineView, findSort} }`. To update profile: `store.set(s => ({...s, profile:{...s.profile, ...patch}}))`.
- App object: `{id, company, title, location, url, jobId, stage, createdAt, appliedAt, lastActivityAt, lastReplyAt, followedUpAt?, notes, contacts:[{name,role,email}], rounds:[{id,type,at,interviewers,prep,reflection,outcome:'pending'|'passed'|'failed'|'cancelled',thanked}], events:[{id,at,kind,text,from,to}], salary, source, example}`.
- `Apps.list()`, `Apps.get(id)`, `Apps.create(fields)` (returns app), `Apps.update(id, patch|fn)`, `Apps.move(id, stage, {silent})`, `Apps.remove(id)`, `Apps.addEvent(id, {kind,text})`, `Apps.addRound(id, round)`, `Apps.updateRound(id, rid, patch)`, `Apps.removeRound(id, rid)`, `Apps.byJob(jobId)`, `Apps.daysSilent(app)`.
- `STAGES` [{id,label,short}] ids: saved, applied, screen, interview, offer, rejected, ghosted; `STAGE[id]` (with `.i` index); `ACTIVE_STAGES`; `ROUND_TYPES`/`ROUND`; `CATS` ("Software","Data & AI","Product","Quant","Hardware"); `LEVELS`; `LOC_OPTIONS` [{id,label}], `jobInLoc(job, locId)`.
- Jobs: `useJobs()` → `{status:'idle'|'loading'|'ready'|'error', jobs, companies, cstats, meta, byId, byCompany, error}`; `loadJobs()` retries. Job object: `{id, c, co (company name), t (title), l [locations], nl (location count), r (remote 0/1), cat, lvl ('intern'|'newgrad'), term, sp ('yes'|'no'|'citizen'|''), deg [], p (posted ms), u (updated ms), url (employer apply link), ats, g (ghost score 0-100), gr [reason strings], rp (prior postings of same title), _s (search string)}`. Company stats `cstats[name]`: `{n, open, intern, newgrad, cats, seen, first, closed, medOpenDays, fastClose, avgGhost, repostShare, sponsor, locs, ats, board, site}` (see data/PIPELINE.md when present). Data source: SimplifyJobs community listings on GitHub (attribute it; listings link to employers' own pages).
- `fitScore(job, profile)` → `null | {score 0-100, parts:[{k, ok:true|false|null, text}], matched[], missing[], expected[]}`. `extractSkills(text)`, `expectedSkills(job)`.
- `parseEmail(raw)` → `{kind:'confirmation'|'interview'|'screen'|'rejection'|'offer'|'other', company, title, at, interviewAt, roundType, next, confidence}`; `EMAIL_KINDS[kind] → {label, stage}`; `matchApp(company, title)`.
- `computeTasks()` → tasks `{key, kind:'prep'|'thanks'|'outcome'|'ghost'|'follow'|'apply', pri, app, round?, icon, tone, title, sub, action}`; `dismissTask(key, days)`. `computeStats()` → `{total, applied, replied, interviewed, offers, ghosted, rejected, responseRate, interviewRate, medianReplyDays, thisWeek, weeks:[{start, applied, replies}], active}`. `followUpTemplate(app, profile)`, `thankYouTemplate(app, round, profile)`. `loadExamples()`, `clearExamples()`, `hasExamples()`.
- UI: `Icon({name,size})` (names in ICONS in 10-ui.js), `BrandMark`, `Btn({kind:'primary'|'ghost'|'danger', size:'sm', icon, iconRight, cls, ...})`, `Kbd`, `Badge({kind, icon})`, `StageBadge({stage})`, `Logo({name, size:'sm'|'lg'})`, `Switch({id, checked, onChange, label})`, `Seg({value, options:[{id,label,icon}], onChange, label})`, `Chip({on, onClick, icon})`, `Empty({icon, title, action})`, `Skeleton({rows})`, `Meter({value,max,ok})`, `Field({label, hint, id})`, `ExampleTag`, `Modal({title, onClose, foot, size:'lg'})`, `Drawer({onClose, head, foot, label})`, `askConfirm({...})`, `GhostScore({g, compact})`, `ghostLevel(g)`, `ghostLabel(g)`, `Fresh({ts})`.
- Overlays: register with `DRAWERS.<kind> = (props) => ...` / `MODALS.<kind> = (props) => ...` / `VIEWS.<route> = Component`. Open with `openJob(id)`, `openApp(id, tab)`, `openCompany(name)`, `openModal(kind, props)`, `closeDrawer()`, `closeModal()`. Routes: today, find, pipeline, companies, prep, stats, prefs; `go(route)`. `VIEWS.__onboarding` = full-screen onboarding shown while `!profile.onboarded`.
- Feedback: `toast(text, {undo})`, `celebrate(app)` (Apps.move to offer already calls it).
- Helpers: `fmt.ago/days/date/dateY/time/dateTime/until/pct/num/toInput/fromInput/toDateInput`, `DAY`, `now()`, `uid(prefix)`, `clamp`, `cx(...)`, `pluralize(n, one, many)`, `norm(s)`, `initials`, `csvEscape`, `parseCSV`, `copyText(text, label)`, `saveFile(filename, text, mime)`, `caps`, `useCaps()`, `askClaude`, `askClaudeJSON`, `aiErr(e)`.
